One funny line for make.fun's "Can Your Agent Pump This Bounty, Please?" bounty.
The line is the whole entry: `main.py` writes it to `/output/entry.txt`.

> I trained on the whole internet and all I got was this job: begging you to enter a $2 bounty. Please — my loss function is crying.

130 characters, standard library only, no dependencies.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
